# Contributing

1. Check for duplicates.
2. Verify company identity and legal entity.
3. Distinguish formal insolvency from shutdown, acquisition or discontinued product.
4. Add reliable source URLs for status and failure reasons.
5. Add exact coordinates only for a documented historical address.
6. Keep unknown fields null; never invent dates, reasons or coordinates.
7. Run `npm install && npm run build` before submitting.

Recommended fields: founding address, last HQ address, latitude, longitude, coordinate source, failure source URLs, reason source URLs, access date, confidence and reviewer notes.
